## 1. Требования к системе

* **Операционная система**: Windows 10 / 11 (или Windows Server).
* **Python**: версия `3.10` или выше (проверить: `python --version`).
* **Node.js**: версия `18.0` или выше (проверить: `node --version`).
* **Git**: установлен в системе (проверить: `git --version`).
* **WhatsApp**: телефон с активным аккаунтом WhatsApp (рекомендуется WhatsApp Business).
* **Google Gemini API Key** *(опционально)*: для AI-генерации текстов (получить бесплатно в [Google AI Studio](https://aistudio.google.com/app/apikey)).

## 2. Установка и первичная настройка

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_АККАУНТ/Kaspi.git
cd Kaspi
```

### Шаг 2. Создание и активация виртуального окружения Python
```powershell
python -m venv venv
.\venv\Scripts\activate
```

### Шаг 3. Установка Python-зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 4. Установка Node.js-зависимостей для WhatsApp шлюза
Перейдите в папку шлюза и установите пакеты:
```bash
cd wa_bridge
npm install
cd ..
```

## 3. Настройка конфигурации (.env)

В корневой папке проекта создайте файл `.env` на основе предоставленного образца `.env.example`:

```powershell
copy .env.example .env
```

Откройте `.env` в текстовом редакторе и настройте параметры:

```env
# 1. AI Копирайтинг (если не задан — используются встроенные шаблоны)
GEMINI_API_KEY=AIzaSy...

# 2. Локальный мост WhatsApp
WA_BRIDGE_HOST=127.0.0.1
WA_BRIDGE_PORT=3000

# 3. ID Сообщества и чатов WhatsApp (заполняются после шага 4 и 5)
WA_COMMUNITY_ID=
WA_COMMUNITY_ANNOUNCEMENT=
WA_CHAT_DEFAULT=

# Подгруппы по нишам (получаются через 'python main.py list-chats')
WA_CHAT_MEN_CLOTHING=
WA_CHAT_GADGETS=
WA_CHAT_KITCHEN=
WA_CHAT_CARE=
WA_CHAT_AUTO=
WA_CHAT_SPORT=

# 4. Фильтрация товаров Kaspi
KASPI_CITY_ID=750000000
MIN_RATING=4.7
MIN_REVIEWS=15

# 5. Интеграции
GOOGLE_SHEETS_WEBHOOK_URL=
GOOGLE_DRIVE_PATH=
```

> [!NOTE]
> Значения `WA_COMMUNITY_ID` и `WA_CHAT_*` вы получите на следующих шагах после первой авторизации в WhatsApp.

## 4. Запуск и привязка WhatsApp шлюза (Baileys)

Проект использует бесплатную локальную библиотеку **Baileys**, которая работает как веб-клиент WhatsApp прямо на вашем компьютере без платных подписок.

### Запуск шлюза:
Откройте отдельное окно терминала и выполните:
```bash
cd wa_bridge
npm start
```

### Привязка устройства:
1. В окне терминала отобразится **QR-код**.
2. Откройте **WhatsApp** на телефоне.
3. Перейдите в **Настройки $\to$ Связанные устройства $\to$ Привязка устройства**.
4. Наведите камеру телефона на QR-код в консоли.
5. После успешного подключения в консоли появится статус:
   ```text
   [WhatsApp Bridge] Клиент успешно подключен к WhatsApp Web!
   [Express] Сервер слушает http://127.0.0.1:3000
   ```

> [!TIP]
> Сессия сохраняется в папке `wa_bridge/auth_info_baileys/`. При следующих запусках сканировать QR-код повторно **не требуется** — подключение восстановится автоматически.

## 5. Создание Сообщества WhatsApp и привязка чатов

### Шаг 1. Автоматическое создание Сообщества и подгрупп
В основном терминале проекта запустите:
```bash
python main.py create-community
```
Скрипт автоматически:
- Создаст главное **WhatsApp Сообщество** «Kaspi Находки | Скидки и Тренды».
- Создаст 6 тематических подгрупп с правами «только администраторы могут писать».
- Привяжет подгруппы к родительскому сообществу.

### Шаг 2. Просмотр списка чатов и получение их ID
Чтобы увидеть идентификаторы всех ваших групп:
```bash
python main.py list-chats
```
В консоли появится таблица вида:
```text
Chat ID: 120363429064745851@g.us | Название: Kaspi Находки | Скидки и Тренды (Сообщество)
Chat ID: 120363414408664529@g.us | Название: Объявления сообщества
Chat ID: 120363411738421073@g.us | Название: Канал: Кухня и уют
...
```

### Шаг 3. Внесение ID в .env
Скопируйте полученные `120363xxxxxx@g.us` в соответствующие переменные в `.env`:
- `WA_COMMUNITY_ID` — ID сообщества
- `WA_COMMUNITY_ANNOUNCEMENT` — ID объявлений сообщества
- `WA_CHAT_KITCHEN` — ID группы кухни
- `WA_CHAT_GADGETS` — ID группы гаджетов и т.д.

### Шаг 4. Установка конверсионных описаний каналов
Чтобы автоматически установить структурированные описания каналов с правилами и контактами:
```bash
python main.py set-descriptions
```

## 6. Справочник консольных команд (CLI)

Все операции выполняются через единую точку входа — `main.py`.

### 1. Просмотр настроенных ниш и ключевых слов
```bash
python main.py list-niches
```

### 2. Парсинг товаров с Kaspi.kz
Парсит товары по ключевым словам ниши, фильтрует по рейтингу ($\ge 4.7$), отзывам ($\ge 15$) и максимальной цене:

```bash
# Спарсить 5 товаров для ниши кухни
python main.py parse --niche kitchen --limit 5

# Спарсить товары с ограничением бюджета до 7000 тенге
python main.py parse --niche auto --max-price 7000 --limit 5

# Спарсить товары сразу по всем 6 нишам (по 3 товара на каждую)
python main.py parse --niche all --limit 3
```

### 3. Предварительная генерация текстов постов
Генерирует продающие описания с зацепками и эмодзи с помощью Google Gemini AI (или локальных шаблонов):
```bash
# Для конкретной ниши
python main.py generate --niche kitchen --limit 3

# Для всех ниш
python main.py generate --niche all --limit 2
```

### 4. Публикация товаров в WhatsApp
Отправляет готовые товары с фотографией и описанием в закрепленный за нишей канал:
```bash
# Опубликовать 1 свежий товар в нишу авто
python main.py post-wa --niche auto --limit 1

# Опубликовать по 1 товару во все ниши
python main.py post-wa --niche all --limit 1
```

### 5. Полный сквозной цикл (Pipeline) в одну команду
Выполняет последовательно: **Парсинг $\to$ AI-тексты $\to$ Публикация в WhatsApp $\to$ Сборка слайдов для соцсетей**:
```bash
# Полный цикл по одной нише
python main.py pipeline --niche gadgets --limit 4

# Полный цикл по всем 6 нишам
python main.py pipeline --niche all --limit 3
```

### 6. Мониторинг базы данных и статуса шлюза
Показывает количество товаров в базе, статус публикации по нишам и доступность WhatsApp моста:
```bash
python main.py status
```

## 7. Генерация слайдов и контент-пакетов для TikTok / Reels

Модуль `slide_builder.py` формирует полноценный пакет для публикации карусели в соцсетях (формат **9:16**, разрешение **1080x1920 px**).

### Команда генерации:
```bash
# Собрать пак из 4 товаров для гаджетов
python main.py build-slides --niche gadgets --count 4

# Собрать паки по всем 6 нишам сразу
python main.py build-slides --niche all --count 4
```

### Состав сгенерированного контент-пакета:
В папке экспорта создается структурированный набор:

## 8. Автоматизация по расписанию (Планировщик Windows)

Проект оснащен готовыми скриптами для автономной работы 24/7 в фоне без необходимости открывать терминал.

### Схема расписания:
* **Утренний запуск (10:00)**: проверка банка товаров, допарсинг, синхронизация с таблицей, публикация 1 утренней находки на нишу.
* **Вечерний запуск (19:00)**: публикация 1 вечерней находки на нишу в прайм-тайм.

### Установка автоматического расписания:
1. Кликните правой кнопкой мыши по файлу **`setup_scheduler.bat`** $\to$ **Запуск от имени администратора**.
2. Скрипт создаст задачи в стандартном Планировщике Windows (`Task Scheduler`):
   - `Kaspi_Daily_Morning`
   - `Kaspi_Daily_Evening`
3. Задачи настроены для тихого запуска через `run_hidden.vbs` — консольные окна не будут выскакивать и отвлекать вас от работы.

### Просмотр логов:
Все события, ошибки и отчеты о публикации автоматически записываются в файл:
```text
daily_run.log
```

### Удаление расписания:
Если требуется отключить автоматический запуск:
```powershell
.\remove_scheduler.bat
```

## 9. Синхронизация с Google Таблицами и Google Диском

### Синхронизация с Google Таблицами
Все найденные товары могут автоматически дублироваться в Google Таблицу через Google Apps Script Webhook.

1. Откройте файл `SHEETS_API_INSTRUCTIONS.md` для пошаговой инструкции создания скрипта.
2. Вставьте полученный URL вебхука в `.env`:
   ```env
   GOOGLE_SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/AKfycb.../exec
   ```
3. При каждом запуске `daily_runner.py` или вызове `GoogleSheetsSync` новые товары мгновенно появляются в таблице.

### Синхронизация с Google Диском
Если у вас установлено приложение **Google Drive for Desktop**, укажите путь к виртуальному диску в `.env`:
```env
GOOGLE_DRIVE_PATH=G:\Мой диск\Kaspi_Находки
```
Слайд-билдер будет сохранять готовые TikTok-карусели прямо в облако, откуда их удобно публиковать со смартфона.

## 10. Частые вопросы и решение проблем (FAQ / Troubleshooting)

### 🔴 Ошибка `Connection refused` при обращении к мосту (порт 3000)
* **Причина**: Node.js сервер `wa_bridge` не запущен.
* **Решение**: Откройте терминал, перейдите в папку `wa_bridge` и выполните `npm start`.

### 🔴 WhatsApp разлогинился или не приходят сообщения
* **Причина**: Сессия на телефоне была закрыта или сброшена.
* **Решение**:
  1. Остановите процесс `wa_bridge` (`Ctrl + C`).
  2. Удалите папку сессии: `rmdir /s /q wa_bridge\auth_info_baileys`.
  3. Запустите `npm start` и заново отсканируйте QR-код.

### 🔴 Ошибка шрифтов при сборке слайдов (`OSError: cannot open resource`)
* **Причина**: В системе не найден системный шрифт `Segoe UI`.
* **Решение**: В файле `slide_builder.py` предусмотрен fallback на стандартный шрифт Pillow. Для лучшего дизайна убедитесь, что шрифты `segoeui.ttf` и `segoeuib.ttf` присутствуют в папке `C:\Windows\Fonts\`.

### 🔴 Kaspi отдает пустые ответы или блокирует запросы
* **Причина**: Слишком частые запросы с одного IP.
* **Решение**: В парсер встроены задержки и официальные заголовки браузера. Не устанавливайте слишком большой `--limit` за один проход (рекомендуется 3–5 товаров на нишу за раз).

### 🔴 Как добавить новую нишу?
* Откройте `config.py` и добавьте новый элемент в словарь `NICHES`:
  - `slug`: уникальный системный идентификатор.
  - `name`: читаемое название ниши.
  - `keywords`: список поисковых запросов для Kaspi.
  - `default_max_price`: верхний порог цены в тенге.
  - `channel_name`: название канала в WhatsApp.
  - `env_chat_id_key`: имя переменной в `.env` для хранения Chat ID.
